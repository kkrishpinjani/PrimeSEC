# SAP Gateway security

SAP Help: https://help.sap.com/saphelp_em92/helpdata/en/48/b2096e7895307be10000000a42189b/content.htm

SAP Gateway security includes host access controls, reginfo/secinfo rules for external programs, and Gateway logging. The applicable release and active ACL files matter.

Inspect profile parameters and active ACL files, identify wildcard rules, and verify parameter semantics for the exact SAP release. A suspicious line is a lead for review, not proof of an exploitable condition.
