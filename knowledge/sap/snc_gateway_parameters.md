# SNC support on SAP Gateway

SAP Help: https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/d6bdcb25438d4405b9f543aa95f48f0d/009e1aa5d7a64ea5bccf87304bf0246f.html

SAP documentation states that snc/enable controls Gateway SNC support. It also describes snc/permit_insecure_start as permitting connections to non-SNC programs when enabled. Whether settings violate policy depends on the system design and SAP release.

Compare settings to the approved baseline, confirm integration requirements, and validate only in a controlled environment.
